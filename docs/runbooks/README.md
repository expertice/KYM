# Runbooks К.У.М.

Операционные инструкции: запуск, диагностика, инциденты.

## Статус

Runtime ещё не развёрнут. Ниже — заготовки разделов.

## Планируемые runbooks

| Runbook | Назначение |
|---------|------------|
| local-dev | Локальный запуск backend + Unity WebGL |
| deploy | Выкат стенда / окружения |
| incident-simulation | Сбой симуляции, ретраи, идемпотентность |
| incident-concurrency | Конфликты версий (optimistic concurrency) |
| backup-restore | Резервное копирование и восстановление |

## Принцип

Любой инцидент, потребовавший ручных шагов, должен завершаться PR с обновлением соответствующего runbook.
