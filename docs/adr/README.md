# Architecture Decision Records (ADR)

Каталог архитектурных решений К.У.М.

## Формат

Каждый ADR содержит:

- **Статус** — Proposed / Accepted / Deprecated / Superseded
- **Контекст** — зачем нужно решение
- **Решение** — что принято
- **Последствия** — плюсы, минусы, риски
