# ADR-0004: Вложенные миры как дерево

- **Статус:** Accepted
- **Дата:** 2026-09-27
- **Участники:** команда К.У.М.

## Контекст

Управленческие контексты бывают вложенными: холдинг → компания → дивизион → команда. Модели и симуляции должны учитывать иерархию без циклов и с предсказуемыми правилами наследования/изоляции.

## Решение

**Миры образуют дерево** (один родитель, много детей; один корень или лес корней в рамках tenant — уточняется на уровне продукта):

- каждая сущность модели привязана к конкретному миру;
- операции чтения/записи учитывают путь в дереве и политики видимости;
- перемещение поддерева — отдельная командная операция с проверками инвариантов;
- циклы запрещены на уровне домена и persistence.

## Последствия

**Плюсы**

- Естественная модель оргструктур и масштабирования.
- Простые алгоритмы обхода (ancestors/descendants).

**Минусы / риски**

- Сложные permission-правила по иерархии.
- Переезды больших поддеревьев требуют транзакционной осторожности.

**Следствия для реализации**

- Хранение: adjacency list + materialized path или closure table (выбор — отдельный ADR при реализации persistence).
- Тесты инвариантов дерева обязательны.
