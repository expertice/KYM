# ADR-0003: Серверная симуляция

- **Статус:** Accepted
- **Дата:** 2026-09-27
- **Участники:** команда К.У.М.

## Контекст

Симуляция управленческих моделей должна быть воспроизводимой, защищённой от манипуляций на клиенте и согласованной для всех участников, работающих с одной моделью/миром.

## Решение

**Симуляция выполняется на сервере**:

- клиент отправляет команды/параметры запуска;
- сервер валидирует вход, исполняет симуляцию, сохраняет результат и audit;
- клиент получает статус, прогресс (при необходимости) и итоговый snapshot/diff;
- детерминизм (seed, версия правил) фиксируется в метаданных `SimulationRun`.

## Последствия

**Плюсы**

- Единый источник истины и аудируемость.
- Возможность масштабировать compute независимо от клиента.
- Защита бизнес-правил от обхода через модифицированный клиент.

**Минусы / риски**

- Нагрузка на backend; нужны очереди/лимиты для долгих runs.
- Latency UX — компенсируется статусами и optimistic UI только для некритичных локальных действий.

**Следствия для реализации**

- Запрещено считать клиентский результат симуляции каноническим.
- Версия движка симуляции версионируется вместе со схемами.
