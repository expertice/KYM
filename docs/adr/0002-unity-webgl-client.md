# ADR-0002: Unity WebGL как клиент

- **Статус:** Accepted
- **Дата:** 2026-09-27
- **Участники:** команда К.У.М.

## Контекст

Клиент К.У.М. должен визуализировать иерархию миров, модели и результаты симуляции в интерактивной среде, доступной из браузера без отдельной установки толстого клиента для базовых сценариев.

## Решение

Основной клиент — **Unity (WebGL build)**:

- UI, визуализация графов/миров, локальный optimistic UX;
- клиент **не** является источником истины для состояния моделей и результатов симуляции;
- обмен с backend по версионированным API/схемам;
- нативные/desktop-сборки Unity допускаются позже как дополнительный target, не меняя серверные контракты.

## Последствия

**Плюсы**

- Богатая 2D/3D-визуализация и единый toolchain Unity.
- Доставка через браузер (WebGL).

**Минусы / риски**

- Ограничения WebGL (память, потоки, размер билда).
- Более сложный CI для Unity, чем для чисто web-фронта.

**Следствия для реализации**

- Контракты API проектируются client-agnostic.
- Тяжёлая логика симуляции не переносится в клиент (см. ADR-0003).
