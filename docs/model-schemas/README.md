# Схемы моделей К.У.М.

Канонические схемы доменных сущностей и симуляционных структур.

## Статус

JSON Schema / protobuf / иные формальные схемы будут добавлены вместе с доменным слоем.
До этого источник истины — ADR и product-описания.

## Планируемые сущности (черновик)

- **World** — узел дерева миров
- **Model** — управленческая модель внутри мира
- **Actor / Role** — участники и роли
- **Resource** — ресурсы и ограничения
- **SimulationRun** — запуск и результат симуляции
- **AuditEvent** — запись аудита изменений

## Правила

1. Схема меняется только через PR с обновлением тестов контрактов.
2. Breaking changes требуют новой версии схемы и записи в CHANGELOG.
3. Клиент Unity потребляет версии схем явно, без «тихих» допущений.
