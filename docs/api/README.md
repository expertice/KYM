# API К.У.М.

Публичные и внутренние контракты API.

## Статус

Спецификации OpenAPI/AsyncAPI появятся после первого среза application-слоя.
До этого изменения API описываются в ADR и PR, затем переносятся сюда.

## Планируемое содержание

- REST/HTTP команды и запросы
- События / realtime-каналы (при необходимости)
- Коды ошибок и идемпотентность
- Версионирование API
